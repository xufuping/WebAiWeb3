# AI 学习规划

## 📌 标签

- AI
- Agent
- LLM
- Tools
- Web3

## 📝 内容

针对当前 AI 技术栈的学习与工具整理，涵盖编码助手、Agent 管理、技能扩展及 Web3 融合等方向。

### 🤖 AI 编码助手与工具箱 (AI Coding Assistants & Tools)

- **[Everything Claude Code](https://github.com/affaan-m/everything-claude-code/blob/main/README.zh-CN.md)**
  Claude Code 全方位优化指南（5万+ Star），涵盖技能、记忆优化、安全扫描、Hooks、MCP 配置等，适用于 Claude Code/Codex/Cursor 等多种 Agent，是系统学习 AI Agent 调优的必读资源。

- **[Antigravity Claude Proxy](https://github.com/badrisnarayanan/antigravity-claude-proxy)**
  将 Antigravity/Google Cloud Code 提供的 Claude/Gemini 模型代理为 Anthropic API 格式，让你免费在 Claude Code CLI 中使用这些模型。
  > 【Antigravity Claude Proxy 是一个中间人服务器（Proxy），它的主要作用是让你能够免费（或利用已有账号）使用 Anthropic 的 Claude Code CLI 工具或其他兼容 API 的 AI 工具】(注意：可能违反 Google ToS，有封号风险)。

### ⚙️ Agent 管理与工作流 (Agent Management & Workflow)

- **[Superset](https://superset.sh/)**
  并行 AI 编码代理管理工具（macOS 桌面端），支持同时运行 10+ 个 Claude Code/Codex/Cursor 等编码 Agent，每个 Agent 在独立 Git worktree 中工作，互不冲突，极大提升开发效率。
  > 【适合终端同时跑多个AI工具、多个AI任务】

- **[Beads (bd)](https://github.com/steveyegge/beads)**
  分布式、Git 驱动的图状任务追踪器，专为 AI Agent 设计。提供结构化记忆、依赖感知的任务图、多 Agent/多分支无冲突工作流。
  > 【解决上下文丢失：AI 可以查询 bd ready 来获取当前未完成的任务。利用 Git：任务被存储在项目目录的 .beads/ 文件夹中。清晰的流水线：定义任务依赖关系。结构化数据：使用 SQLite 作为本地读取缓存。】

- **[nanobot](https://github.com/HKUDS/nanobot/tree/main)**
  OpenClaw 的超轻量替代版，代码量极少，适合阅读源码学习"如何从零构建一个 AI Agent"。
  > 【适合用来本地学习，对前端/全栈工程师理解 Agent 架构很有帮助】

- **[n8n](https://github.com/n8n-io/n8n?tab=readme-ov-file)**
  开源工作流自动化平台（17万+ Star），内置 AI/LangChain 能力，可视化拖拽构建自动化流程。
  > 【适合搭建 AI 驱动的自动化工作流，如自动部署、数据处理、通知推送等】

### 🧩 技能扩展与生态 (Skills & Extensions)

- **[skills.sh](https://skills.sh/)**
  AI Agent 技能开放市场/目录，一条命令即可安装各种技能，浏览排行榜发现高质量技能。

- **[Vercel Agent Skills - Web Design Guidelines](https://github.com/vercel-labs/agent-skills/blob/web-design-guidelines/skills/web-design-guidelines/SKILL.md)**
  Vercel 官方出品的 Web 设计规范技能，安装后 AI Agent 生成的前端页面会自动遵循现代 Web 设计最佳实践。

- **[Vercel Agent Skills - React Best Practices](https://github.com/vercel-labs/agent-skills/blob/react-best-practices/skills/react-best-practices/SKILL.md)**
  Vercel 官方的 React 最佳实践技能，让 AI Agent 按照 React 最新范式写代码。

- **[UI UX Pro Max Skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)**
  AI UI/UX 设计智能技能（3.5万+ Star），内置设计系统生成器，能根据项目需求自动推荐配色、布局、组件模式。

- **[Skill Seekers](https://github.com/yusufkaraaslan/Skill_Seekers/blob/main/README.zh-CN.md)**
  将文档网站/GitHub 仓库/PDF 自动转换为 AI 技能的工具，支持导出为 Claude Skills/RAG 管道/Cursor Rules 等格式。
  > 【一键把任何文档变成 AI 可消费的结构化知识】

### 🏠 本地 LLM 与服务 (Local LLM & Services)

- **[乌萨奇AI](https://537-ai.net/)**
  为 AI 编程用户打造的高质量 API 服务，支持 Claude、Gemini，兼容 OpenAI 格式。
  > 【主打一个省钱】

- **[Ollama](https://ollama.com/)**
  本地运行大语言模型的工具，一行命令即可在 Mac/Linux 上跑开源 LLM。
  > 【适合离线开发、隐私敏感场景和模型实验】

### 📰 资讯与趋势 (Information & News)

- **[ClawFeed](https://clawfeed.kevinhe.io/)**
  AI 新闻聚合站，提供 4 小时/日/周/月等不同粒度的 AI 领域新闻简报。

- **[last30days-skill](https://github.com/mvanhorn/last30days-skill)**
  AI 趋势调研技能，自动搜集过去 30 天的热门讨论并生成报告。
